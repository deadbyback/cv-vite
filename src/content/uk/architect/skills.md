# Навички

## Архітектура та проєктування
- **Clean Architecture** — основний підхід для нових модулів: entities, use cases, adapters, infrastructure
- **Domain-Driven Design (DDD)** — bounded contexts, агрегати, доменні події, ubiquitous language
- **Мікросервіси** — декомпозиція сервісів, API-контракти, event-driven комунікація
- **Модульний моноліт** — перехідний патерн для міграції legacy із збереженням deployability
- **REST API Design** — моделювання ресурсів, версіонування, документація (OpenAPI)

## Backend
- **PHP 8.3** — 6+ років · Основна мова · Yii2 framework
- **Go** — 1 рік · Міграція сервісів, компоненти з вимогами до продуктивності
- **.NET / C#** — 1+ рік · Сервіси-парсери, обробка даних
- **Python** — 2+ роки · Геопросторові скрипти, GDAL/OGR пайплайни
- **Node.js** — 2+ роки · API-інтеграції, інструментарій

## Дані та геопростір
- **PostgreSQL / PostGIS** — 6+ років · Партиціонування, реплікація, складні геозапити
- **AWS RDS** — Managed PostgreSQL з read-only репліка на Hetzner
- **GDAL / OGR** — Обробка геопросторових даних та конвертація форматів
- **GeoServer** — WMS/WFS тайловий сервер для map-клієнтів
- **SeaweedFS** — S3-сумісне розподілене об'єктне сховище

## Інфраструктура та DevOps
- Docker, Docker Compose
- AWS (RDS), Hetzner (self-hosted)
- GitLab CI/CD (у процесі для деплою моноліту)
- OpenObserve · Sentry · New Relic

## Frontend (вторинне)
- Vue.js 2/3 — 3+ роки (Vue 2 у production; Vue 3 у особистих проєктах)
- TypeScript, JavaScript, HTML/CSS

## AI та LLM-інструменти
- **Розгортання self-hosted LLM**: задеплоїв Qwen 3.5 локально на сервері для внутрішнього тестування — оцінив можливості моделі, продуктивність inference та feasibility інтеграції
- **MCP-розробка**: будую Model Context Protocol сервер для інтеграції GitLab — надає AI-агентам доступ до даних репозиторію, MR та CI пайплайнів (у процесі)
- **AI-асистована розробка**: Claude Code як основний інструмент; щоденна інтеграція у воркфлоу
